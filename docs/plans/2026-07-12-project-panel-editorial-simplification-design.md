# Project panel editorial simplification

## Goal

Reduce the visual density of the desktop project panel without removing project content. The panel should feel like the beginning of a continuous story and invite scrolling instead of looking complete after its first viewport.

## Panel-only changes

- Remove the project image from the desktop side panel.
- Keep the image in the existing full-page mobile case study.
- Replace filled and bordered CTA buttons with quiet inline text links.
- Remove the boxed status, type, impact, and proof snapshot.
- Show role, year, status, and type as one muted metadata line below the title.
- Show impact and proof as short, unboxed list items.
- Use smaller editorial labels for section headings.
- Reduce vertical gaps between sections.
- Render process, migration, and learning lists without numbered circles or decorative cards.
- Render technologies as inline text separated by middle dots instead of pills.
- Keep all populated case-study fields and their current order.

## Continuity

The title, metadata, summary, links, and impact facts should occupy less than the first viewport so the start of the following narrative section remains visible and signals that more content continues below.

## Verification

- Confirm that the panel contains no project image.
- Confirm that mobile full-page case studies still contain their image.
- Confirm links remain keyboard accessible and open in a new tab.
- Confirm every populated content field still renders.
- Confirm Spanish and English layouts use the same hierarchy.
